# Repozytorium projektu na przedmiot Algorytmy w inżynierii danych na Politechnice Warszawskiej w semestrze 2025L
Celem projektu było stworzenie własnej biblioteki do automatycznego różniczkowania w języku Julia a następnie wykorzystanie jej na przykładzie uczenia sieci neuronowej (rekurencyjnej lub konwolucyjnej) do klasyfikacji sentymentu opinii z bazy IMDb. W zakres projektu wchodziło:
- implementacja własnej biblioteki do automatycznego różniczkowania z akumulacją gradientu wstecz
- implementacja własnej biblioteki do uczenia sieci neuronowych
- wykorzystanie biblioteki do nauczenia sieci w wybranej architekturze (+ MLP)
- implementacja dodatkowego rozwiązania referencyjnego
- wykonanie testów porównawczych z rozwiązaniami referencyjnymi oraz optymalizacja
własnej implementacji


W tym repozytorium zaimplementowane zostały sieci MPL oraz sieć konwolucyjna. Ich przykładowe wykorzystanie zostało przedstawione w notatnikach w katalogu ``my_AD_library/test``.
